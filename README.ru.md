<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Meshify/raw/main/assets/icons/meshifyIcon.png" width="35"/> Meshify</h1>

<p align="center">
  Meshify это приложение для обнаружения лицевой сетки в реальном времени, использующее OpenCV, MediaPipe и CVZone для точного и эффективного определения и отслеживания лицевых ориентиров.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Meshify/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
|---|---|
| 👁️ **Отслеживание лица в реальном времени** | Мгновенно обнаруживает и отслеживает черты лица с помощью камеры. |
| 🎯 **Точное обнаружение ориентиров** | Определяет до 468 лицевых ориентиров для детального анализа лица. |
| 🚀 **Высокая скорость обработки** | Обеспечивает плавную работу с минимальной задержкой. |
| 🛠️ **Гибкая настройка** | Позволяет легко изменять параметры обнаружения лицевой сетки. |

## <img src="https://github.com/KrishBharadwaj5678/Meshify/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Meshify.git
```

### 2️⃣ Переход в папку проекта

```bash
cd Meshify
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
python app.py
```
