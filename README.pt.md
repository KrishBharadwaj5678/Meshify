<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Meshify/raw/main/assets/icons/meshifyIcon.png" width="35"/> Meshify</h1>

<p align="center">
  Meshify é uma aplicação de detecção de malha facial em tempo real que utiliza OpenCV, MediaPipe e CVZone para identificar e acompanhar pontos faciais com alta precisão e desempenho.
</p>

![MeshifyDemo](https://github.com/KrishBharadwaj5678/Meshify/raw/main/assets/demos/MeshifyDemo.png)

<img src="https://github.com/KrishBharadwaj5678/Meshify/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/Meshify/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| 👁️ **Rastreamento Facial em Tempo Real** | Detecta e acompanha características faciais instantaneamente através da câmera. |
| 🎯 **Detecção Precisa de Pontos Faciais** | Identifica até 468 pontos faciais para uma análise detalhada do rosto. |
| 🚀 **Processamento de Alta Velocidade** | Proporciona um desempenho suave com baixa latência. |
| 🛠️ **Configuração Flexível** | Permite personalizar facilmente os parâmetros de detecção da malha facial. |

## <img src="https://github.com/KrishBharadwaj5678/Meshify/raw/main/assets/readme/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Meshify.git
```

### 2️⃣ Acessar o Diretório do Projeto

```bash
cd Meshify
```

### 3️⃣ Instalar as Dependências

```bash

```
